
# Todo App

A task management application built with React and TypeScript. The app allows users to create, organize, update, and track their todos through a simple and intuitive interface.

## Features

- **Create todos** with title validation
- **Mark todos as completed** or active
- **Edit todo titles**
- **Delete individual todos**
- **Filter todos** by All, Active, and Completed status
- **Clear completed todos** in one action
- **Toggle all todos** between completed and active
- **Display error notifications** when an operation fails
- **Loading states** for asynchronous operations
- **API integration** to persist todo data

## Technologies

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sofiatsebenko/todo_app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd todo_app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```
